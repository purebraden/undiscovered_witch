# Global KDP Publishing Rules v2 (LOCKED)

These rules apply to **all books and projects** intended for publication via Amazon KDP
(ebook and paperback). They exist to enforce consistency across the series and to
prevent recurring formatting, layout, and submission errors.

This document **supersedes KDP Rules v1**.

---

## RULESET KDP-0 — SCOPE & AUTHORITY

- These rules are **global**, not series-specific
- They apply to **every KDP-bound manuscript**
- They override drafting preferences when conflicts arise
- Refer to this document as **Global KDP Publishing Rules v2 (LOCKED)**

---

## RULESET KDP-1 — FORMAT SEPARATION (NON-NEGOTIABLE)

Every book must have **two distinct master files**:

1. **EBOOK MASTER**
2. **PAPERBACK MASTER**

These files may never share final formatting or be derived from the same styled export
without verification.

---

## RULESET KDP-2 — STANDARD PRINT SPECIFICATIONS (LOCKED)

All paperbacks in this series must use the following specifications unless explicitly
overridden:

- **Trim size:** 5 × 8 inches
- **Interior:** Black & White
- **Paper:** White
- **Bleed:** No bleed
- **Binding:** Perfect bound

These specifications are **series-wide defaults** and must not vary between books.

---

## RULESET KDP-3 — EBOOK FORMAT & RULES

### File Format (MANDATORY)
- Ebook master must be **.docx**
- No PDFs for ebooks

### Layout Rules
- Ebook text must be **reflowable**
- No fixed spacing for visual layout
- All spacing must be **style-based**, never manual

### Table of Contents (MANDATORY)
- Ebook must include a **clickable TOC**
- TOC must be generated from **Heading styles**
- TOC must include:
  - All chapters
  - All interludes
  - Epilogue (if present)

Failure to include a TOC risks rejection and poor Kindle navigation.

### Spacing Rules (CRITICAL)
- No empty lines used for spacing
- No manual line breaks
- No double spacing
- Paragraph spacing must be defined via:
  - Paragraph style spacing-after, or
  - First-line indentation (preferred)

Unintended white space almost always comes from manual spacing.

---

## RULESET KDP-4 — PAPERBACK FORMAT & RULES

### File Format (MANDATORY)
- Paperback master must be **PDF**
- No DOCX uploads for final paperback interiors

### Margin Discipline (CRITICAL)
Margins must be explicitly set to account for:

- Inside (gutter)
- Outside
- Top
- Bottom

Gutter margins must scale with page count to avoid text loss in binding.

Failure to manage margins correctly results in:
- Text crowding the spine
- Rejected proofs
- Poor print readability

### Page Numbers (MANDATORY)
- All paperbacks must include page numbers
- Page numbers:
  - Begin after front matter
  - Do NOT appear on the title page
  - May appear in header or footer

Missing page numbers are a **print failure**, not a cosmetic issue.

---

## RULESET KDP-5 — HEADING & STYLE DISCIPLINE

- Chapter titles must use a consistent Heading style
- Body text must use **one paragraph style**
- Italics allowed for emphasis
- No manual font resizing or centering

Never:
- Manually space chapters
- Mix fonts arbitrarily
- Use tabs for layout

Styles control everything.

---

## RULESET KDP-6 — EXPORT & VALIDATION CHECKLIST

Every book must pass this checklist before upload.

### Ebook Checklist
- [ ] DOCX only
- [ ] Clickable TOC verified in Kindle Previewer
- [ ] No double spacing
- [ ] No excessive white space
- [ ] No page numbers visible
- [ ] Chapters reflow correctly on resize

### Paperback Checklist
- [ ] PDF only
- [ ] Trim size verified at 5 × 8
- [ ] Black & white / white paper confirmed
- [ ] No bleed confirmed
- [ ] Page numbers present and correct
- [ ] Gutter margin sufficient
- [ ] No blank pages mid-book

If any box fails, fix before upload.

---

## RULESET KDP-7 — PREVIEWER IS LAW

- Kindle Previewer is authoritative for ebooks
- Print Preview PDF is authoritative for paperbacks
- Visual inspection is mandatory

Never assume formatting is correct without previewing.

---

## RULESET KDP-8 — VERSION CONTROL

- Ebook and paperback files must be versioned separately
- Filenames must clearly indicate format and version

Examples:
- Book4_EBOOK_FINAL_v1.docx
- Book4_PAPERBACK_FINAL_v1.pdf

---

## FINAL NOTE

KDP problems are almost always **format discipline failures**, not content issues.

These rules exist to enforce consistency, protect print quality, and preserve
publishing velocity. Updates may occur only via versioned revisions.
